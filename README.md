# TOEIC Isles 多益群島

**多益群島 TOEIC Isles** — 多益 TOEIC Listening & Reading 3D 互動練習城
A 3D interactive practice city for the TOEIC Listening & Reading test.

和「守盾群島」同一套玩具風格 3D 引擎：7 座六角小島對應多益七個 Part，加上中央的多益廣場。點選島嶼，分身「小益」就會走過去，看重點、上互動教學、即時答題並看解析。

## 特色 Features
- **聽力語音**：Part 1–4 用瀏覽器內建英文語音即時朗讀，不同說話者配不同聲音，可混用美／英／澳／加口音；可調語速、自動播放。Part 1、2 的文字作答後才顯示，練習時可以「偷看原文」。作答後顯示聽力原文與中譯。
- **題組**：Part 3/4/6/7 以題組呈現，隨機出題時同一篇的題目會保持在一起。
- **互動教學**：分類、填空、翻卡、排序、分層說明，以及聽力專用的「跟讀清單」、「相似音辨識」、「聽寫比對」。
- **單字釣魚碼頭**：八大主題 160 個多益單字，每條魚一個字（含發音、例句）；答錯的字會變成黃金魚再出現。附魚圖鑑與單字本。
- **模擬考**：依正式考試各 Part 比例抽題（迷你／半回／全回，可只考聽力或閱讀），可選「考場模式：聽力只播一次」。交卷後估算聽力、閱讀量尺分數與證書顏色（粗估）。
- 錯題重練、收藏、作答紀錄、島嶼熟練度旗幟、日夜模式、原創配樂（朗讀時自動降低音量）。
- 進度存在瀏覽器的 localStorage，關掉再開也會保留。

## 使用 Usage
用瀏覽器開啟 `index.html`（需連網載入 Three.js）。
建議使用 **Edge**（內建微軟自然語音，聽力最接近真人）或 Chrome。Windows 可到「設定 → 時間與語言 → 語音」加裝英國、澳洲英文語音，網站會自動使用。

## 資料來源 Sources
所有題目、教學與單字都是本專案**依 ETS 官方公布的多益題型與格式原創**，不是 ETS 官方試題。題型結構、各 Part 題數、證書顏色分數區間，以及 Part 1 being/been、Part 2 間接回答與三大陷阱、Part 3/4 預讀與圖表題、Part 7 題型等解題策略，參考了 ETS／IIBC 官方題型說明與多益教學網站的公開整理。量尺分數為依答對率粗估，正式考試每回換算表不同。僅供學習使用。

## 原始碼 Source
`_source/` 內是題庫與建置腳本：
- `data/*.py`：各 Part 題目、互動教學、單字、島嶼重點（正解寫在選項第一個，建置時自動打亂）。
- `parts/*`：改寫後的引擎片段。
- 重新建置：`python build_data.py`，再 `python build_html.py <守盾群島 index.html 路徑> index.html`。
